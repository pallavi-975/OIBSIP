# Landing Page

## Oasis Infobyte Web Development & Designing Internship

This project is a responsive landing page developed as part of Level 1 of the Oasis Infobyte Web Development & Designing Internship.

## Project Description

The Landing Page is designed with a clean and attractive layout to present information in an organized way. It includes a navigation bar, hero section, content sections, call-to-action elements, and a footer.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive design
- Navigation bar
- Attractive hero section
- Well-structured content sections
- Call-to-action section
- Footer
- User-friendly interface

## How to Run

1. Download or clone this repository.
2. Open the `index.html` file in any modern web browser.
3. The landing page will be displayed.
