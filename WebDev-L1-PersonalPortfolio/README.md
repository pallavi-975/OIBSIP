# Personal Portfolio Website

## Oasis Infobyte Web Development & Designing Internship

This project is a personal portfolio website developed as part of Level 1 of the Oasis Infobyte Web Development & Designing Internship.

## Project Description

The Personal Portfolio Website showcases personal information, skills, projects, and other relevant details through a simple and professional web interface.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive layout
- Home section
- About section
- Skills section
- Projects section
- Contact section
- Clean and professional design
- Easy navigation

## How to Run

1. Download or clone this repository.
2. Open the `index.html` file in any modern web browser.
3. The portfolio website will be displayed.
