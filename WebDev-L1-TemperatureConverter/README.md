# Temperature Converter Website

## Oasis Infobyte Web Development & Designing Internship

This project is a temperature converter website developed as part of Level 1 of the Oasis Infobyte Web Development & Designing Internship.

## Project Description

The Temperature Converter allows users to enter a temperature value and convert it between different temperature units. The project demonstrates the use of HTML, CSS, and JavaScript to create an interactive web application.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Temperature conversion
- Supports multiple temperature units
- Interactive user interface
- Input validation
- Responsive design
- Displays the converted temperature clearly

## How to Run

1. Download or clone this repository.
2. Open the `index.html` file in any modern web browser.
3. Enter a temperature value.
4. Select the required temperature units.
5. Click the convert button to view the result.
